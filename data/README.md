# 데이터셋

| 항목 | 내용 |
|---|---|
| 부류 | razor(면도기), toilet_paper(두루마리 휴지), wallet(지갑) |
| 원본 이미지 | 107장, 휴대폰으로 직접 촬영 |
| 라벨링 | Roboflow Auto Label로 자동 라벨링 후 수동 검수 |
| 증강 | Roboflow 버전 생성 시 train 이미지 3배 증강 |
| 분할 | train 228장(원본 76장 × 3) / valid 21장 / test 10장 |

Roboflow에서 내보낸 버전은 분할 없이 321장이 모두 train에 들어 있었다. 그래서 노트북에서 원본 단위로 묶어 valid 20%, test 10%를 떼어냈다.
파일명의 `.rf.` 앞부분이 같은 이미지는 같은 원본의 증강 사본이다. 이 사본들이 train과 평가 세트에 나뉘어 들어가지 않도록 원본 단위로 분할했고, valid와 test에는 원본당 한 장만 남겼다.

이미지 파일은 용량과 개인 촬영물이라는 점 때문에 저장소에 포함하지 않았다. 재현할 때는 노트북 1번 셀에서 Roboflow로 내려받는다.
